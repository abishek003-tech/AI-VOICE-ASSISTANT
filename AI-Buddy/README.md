# AI Buddy – Personal Voice Assistant

A local system AI voice assistant built using Python.

## Features
- Wake word activation
- Voice commands
- Open / close applications
- Time assistant
- Text-to-speech replies

## Tech Stack
- Python
- SpeechRecognition
- PyAudio
- pyttsx3

python main.py
